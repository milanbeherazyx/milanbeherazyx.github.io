# progress-archive/

Rotated-out PROGRESS.md entries, one file per half-year
(`<year>-H<1|2>.md`). Rotation rule: agent/memory.md Layer 2 — when
PROGRESS.md exceeds ~400 lines, its oldest entries move here verbatim and
a one-line stub stays behind. Read these only when investigating old
history; day-to-day work never needs them.
